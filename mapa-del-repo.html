Guía para entender Open MCT

Open MCT: la pantalla de control de misión que se llena con tus datos

Open MCT es una pantalla de control de misión vacía: tú le dices de dónde salen los datos y cómo se llaman, y ella se encarga de pedirlos, guardarlos y dibujarlos en gráficas.

Cómo conectamos Percy

Plan. Todavía no está construido ni instalado

La simulación de Percy corre en el navegador (Vite) y Open MCT corre aparte, en otra dirección. Los navegadores no se pasan datos entre sí por su cuenta, así que hace falta un puente pequeño.

Ya existe window.__rover (src/rover.js:276), que es justo ese objeto state, listo para leerlo.

Pasos

  1. Emisor en la simulación

    Cada 100 ms, leer window.__rover y mandar un JSON {utc, speed, pitch, ...} por WebSocket.

  2. Puente (un script de Node)

    Recibe lo que manda la simulación, lo reenvía a Open MCT en vivo y guarda los últimos minutos para responder al «dame el historial».

  3. Plugin de Percy en Open MCT

    Define el tipo de objeto, el proveedor (con request y subscribe hablando con el puente) y un árbol con una carpeta «Percy» y un hijo por canal. Para el árbol, el ejemplo más cercano es src/plugins/staticRootPlugin/plugin.js:25.

  4. Arranque

    Instalar el reloj UTC (index.html:119), un guardado local (index.html:102), el plugin de Percy y llamar a openmct.start() (index.html:240).

  5. Gráficas

    En la interfaz, arrastrar los canales a una gráfica. No hay que programar la gráfica: el plugin plot ya lo hace.

  6. Al final: las cámaras

    Las piezas Mastcam_Z_cams, NavCams, hazcams_front, hazcams_rear, WATSON, Up_Look_Camera y Down_Look_Camera (guardadas en window.__cameraParts, src/rover.js:265) se pueden mostrar con el plugin de imágenes (src/plugins/imagery/plugin.js:28), mandando una captura de cada cámara como dato.

Esqueleto del proveedor de Percy

// Adaptado de example/generator/plugin.js:64, GeneratorProvider.js:42-47 y TelemetryAPI.js:167.
// Sin probar: el repo de Open MCT no está instalado todavía.
openmct.install(function PercyPlugin(openmct) {
  const esDePercy = (obj) => obj.type === 'percy.canal';

  openmct.types.addType('percy.canal', {
    name: 'Canal de Percy',
    creatable: true,
    initialize(obj) {
      obj.telemetry = { values: [
        { key: 'utc',   name: 'Hora',      format: 'utc', hints: { domain: 1 } },
        { key: 'value', name: 'Valor',     hints: { range: 1 } }
      ] };
    }
  });

  openmct.telemetry.addProvider({
    supportsRequest: esDePercy,
    supportsSubscribe: esDePercy,
    async request(obj, opts) {            // opts.start / opts.end vienen del reloj
      const r = await fetch(`http://localhost:8081/historial/${obj.identifier.key}?desde=${opts.start}&hasta=${opts.end}`,
                            { signal: opts.signal });
      return r.json();                    // [{ utc, value }, ...]
    },
    subscribe(obj, callback) {
      const ws = new WebSocket(`ws://localhost:8081/${obj.identifier.key}`);
      ws.onmessage = (m) => callback(JSON.parse(m.data));   // un dato { utc, value }
      return () => ws.close();            // Open MCT llama esto al dejar de mirar
    }
  });
});
